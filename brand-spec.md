## Type

- Display: Bebas Neue (`font-display`) — used sparingly for masthead wordmarks, never every heading.
- Editorial: Instrument Serif (`font-serif`) — journal titles, deks, italic asides.
- UI: DM Sans (`font-ui`) — body, nav, controls.

## Direction (landing overhaul v3 — folio)

**Reference lock**
- Leading: Monocle digital editorial (grid, hairlines, type hierarchy) + Loro Piana FW24 photo-led quiet luxury
- Carry: Aesop zero-radius, literary dek measure
- Reject: centered 3D logo stack, glass cards, hero metrics, pill CTAs, heavy blur mush

**Composition:** Full-bleed dusk photo (blur ~2.5px). Left folio: VI seal + serif headline + dek + one solid CTA. Right columns breathe. Journal as numbered magazine rows. Boutique as type | photo split.
