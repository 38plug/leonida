# Vice Ops Shop

Premium dropshipping storefront (Night Pass) for Vice Ops. Linked to Agents Office.

- **Dev:** `npm run dev` → http://127.0.0.1:3001
- **Office bridge:** `NEXT_PUBLIC_OFFICE_URL` (default `http://127.0.0.1:3000`)
- **Figma:** https://www.figma.com/design/iDKRY44tyl2naKmdTjp9Yr
- **Design system:** `DESIGN.md` (Stitch / Impeccable)

Commerce counters start at **0**. Spend/publish remain gated in the office.
